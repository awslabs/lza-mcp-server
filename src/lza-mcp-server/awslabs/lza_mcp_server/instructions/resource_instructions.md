

## Resources

Resources expose read-only data that you can discover and access. Depending on the server configuration, resources are available either as native MCP resources or via the `listResources` and `readResource` tools. Use `listResources` to see all available resource URI patterns, then `readResource` with a specific URI to retrieve data.

Available resource topics:
- **Workspace state**: list workspaces, list files in a workspace, read file contents
